# Acme-Corp-SOC-Investigation
SOC Investigation reports and analysis for Acme-Corp project
## Overview
Security incident investigation conducted on Acme-Corp's environment.  
This repository contains the full incident report, raw evidence logs, 
IOCs, and attack timeline documented during the investigation.

## Repository Structure

```
Acme-Corp-SOC-Investigation/
├── reports/
│   ├── IR_Report_ACMECORP_20260415.docx   ← Full incident report
│   └── IR_Report_ACMECORP_20260415.md     ← Readable preview
├── evidence/
│   └── acmecorp_attack_logs_raw.json      ← Raw investigation logs
├── iocs/
│   └── ioc_list_ACMECORP_20260415.md      ← Indicators of Compromise
└── timeline/
    └── attack_timeline_ACMECORP.md        ← Attack chronology
```

## Tools Used
- SIEM / Log Analysis
- JSON log parsing
- Threat Intelligence lookup
- Endpoint Detection & Response (EDR)
